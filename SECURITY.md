# Security Policy

## Reporting a vulnerability

Please report security-sensitive problems privately through GitHub's
**Report a vulnerability** feature:

https://github.com/emike09/Jackdaw-Flag-Patcher/security/advisories/new

Do not include Ubisoft game archives, account credentials, or personal file paths
in a report. Ordinary compatibility bugs can use the public issue tracker.

Only the latest stable release is supported with security fixes.
